Conflict-Free Timetable Scheduling System

A web-based university timetable management and scheduling system developed as a Final Year Project in Computer Systems Engineering.

Overview

Managing university timetables manually can be difficult when multiple courses, instructors, rooms, semesters, and time slots are involved. This project provides a web-based system for managing and viewing academic timetables through a centralized database.

The system allows administrators to manage course information and provides students/users with a structured timetable view based on semester selection.

Key Features

- Semester-based timetable viewing
- Course management through an admin panel
- Administrator login and logout
- Add and delete course information
- Database-driven timetable management
- Display of course, instructor, room, day, and time information
- Printable timetable
- Export timetable to PDF
- Export timetable to Word
- Responsive web-based interface
